Guide

At a glance

New here? Skim this section first. VibeStat-Text by VibeStatics is Windows R text mining software. Load interview, survey, report, paper, news, or policy text — then run frequency, word clouds, LDA, and document comparison with buttons, not scripts. Not only graduate students: also for institutions, practitioners, and classrooms. Designed by an Ed.D. from dissertation and graduate text-mining supervision to lower R entry barriers. It is not a proprietary stats engine — analysis runs on built-in R. See R · trust.

Who it is for

  • Researchers & graduate students — theses, dissertations, journal submissions
  • Faculty — research methods, text mining, mixed-methods labs
  • Public & private institutes — policy, evaluation, project reports, survey & interview data
  • Practice & consulting — client feedback, reviews, proposals, meeting notes
  • Content, media & UX — articles, posts, user feedback — topics, frequency, comparison
  • Anyone who needs reproducible document analysis without heavy R/Python scripting

What you do (in short)

  • Load data — PDF · Excel · CSV · TXT · merge PDFs
  • Button analysis (local R) — morphology · frequency · TF-IDF · word cloud · LDA · doc compare
  • Dictionary & preprocess — stopwords, synonyms, phrases · outputs in .vibestat/output/
  • Optional AI · voice (BYOK) — Vibe-Talk · Vibe-Loom · mic · connect Upstage Solar (chat) + OpenAI Whisper (voice) in app API settings
  • Built-in tutorial · F1 Help — start in about five minutes

Vibe-Talk, Vibe-Loom, and mic voice are optional. In the app API settings, connect an Upstage Solar key (chat) and an OpenAI key (Whisper · mic), then use the microphone in Talk/Loom to dictate. Core text mining runs offline with built-in R — no API key required.

Why we built it · design story

VibeStat-Text was not built from a feature checklist alone. An Ed.D. scholar wrote a dissertation centered on text and document analysis through a far more manual path than this tool provides today — learning R, packages, environment setup, and scripts alone, often wanting to quit along the way.

Later, while supervising graduate students in text mining, the same barriers appeared again: time lost to installation and coding instead of corpus design, research questions, and interpretation. That field experience became the direct motive for development.

The goal is research question → corpus → analysis → interpretation with built-in R, buttons, dictionary & preprocess, and a built-in textbook. Optional Vibe-Talk and Vibe-Loom extend interpretation and drafting (your API key).

The app enables richer exploration and reproducibility than the designer had for their own dissertation — but analysis quality and interpretation remain the researcher’s responsibility. It is for research, institutions, and practice — not a student homework shortcut.

R engine · why you can trust it

VibeStat-Text is not an Excel macro or a black-box stats engine. Analysis runs on your PC via R (Rscript.exe). Each button triggers validated R scripts you can inspect in R Code / Console.

Text mining uses tidytext · quanteda · topicmodels · wordcloud2 and other standard academic R packages. With the same packages, preprocessing, and settings, results follow the same R computation path as running scripts in RStudio (numbers may differ if package versions, stopwords, or seeds differ).

  • Local execution — core mining does not send full corpora to cloud LLMs
  • Saved outputs — CSV and images under .vibestat/output/ for papers and reports
  • Reproducibility aids — dictionaries, preprocessing, and session saves for re-runs
  • Korean morphology — elbird (Kiwi), etc.; LIVE LOG / console records the analyzer used
  • Independent product — not an official R Foundation app; R engine use is disclosed with attribution

Unlike Vibe Coding (AI generates scripts for you), VibeStat-Text helps reproducible R-based text mining through a UI. Vibe-Talk and Vibe-Loom are optional interpretation/drafting aids; the core is local R.

Voice input · API setup (optional)

Frequency · word clouds · LDA · document comparison run without any API key on local R. The steps below apply only to Vibe-Talk · Vibe-Loom · microphone.

  1. Open API settings in the app (top menu or when you first use Vibe-Talk).
  2. Upstage Solar API key — sign up at console.upstage.ai → API Keys → create a key → paste in the app · model solar-pro.
  3. Voice (mic) — under voice, choose Separate OpenAI key (Whisper) → enter your OpenAI API key. When using Solar for chat, Whisper needs a separate OpenAI key.
  4. Save and use → microphone button in Talk/Loom → speak to dictate text.

If you use OpenAI for both LLM chat and voice, one OpenAI key can cover both. Choose “Off (typing only)” if you do not need voice.

Background · text mining theory · R history

Searching for text mining, R programming, topic modeling, word clouds, or TF-IDF? Below is a factual primer with official and academic links. VibeStatics (바이브스타틱스 · 바이브통계) is a Windows tool that runs these academic standards via buttons and built-in R.

What is text mining? — concepts, principles, workflow

Text mining (text analytics) extracts patterns, topics, and frequencies from unstructured text — papers, reports, news, interviews, survey responses. It draws on statistics, information retrieval, NLP, and machine learning. (Wikipedia · Text mining)

A typical research workflow:

  1. Research question & corpus design — documents, periods, groups
  2. Collection & cleaning — PDF · Excel · CSV · TXT, encoding, metadata
  3. Preprocessing & tokenization — stopwords, morphology (Korean), dictionaries
  4. Exploration — word/document frequency, TF-IDF, word clouds
  5. Modeling & comparison — LDA topics, log-odds, networks
  6. Interpretation & reporting — tables, figures, reproducible settings

VibeStat-Text connects steps 2–5 with buttons and built-in R. Apply →

Word frequency · TF-IDF · word clouds — a short primer

Word frequency counts how often terms appear in a corpus; results depend on preprocessing.

TF-IDF highlights terms distinctive to a document by combining term frequency (TF) with inverse document frequency (IDF). (Wikipedia · TF-IDF)

Word clouds visualize weighted terms as font sizes — useful as supplementary figures alongside frequency tables and context. VibeStat-Text uses R packages such as wordcloud2.

LDA · topic modeling — concepts and references

LDA (Latent Dirichlet Allocation) assumes each document is a mixture of latent topics, each topic a distribution over words. (Wikipedia · LDA)

Key paper: Blei, Ng & Jordan (2003), Latent Dirichlet Allocation, JMLR. (JMLR PDF)

VibeStat-Text runs LDA locally via CRAN topicmodels and related packages. Choosing K and interpreting topics remain researcher decisions.

R programming language — history and context

R was created in the 1990s by Ross Ihaka and Robert Gentleman at the University of Auckland for statistical computing and graphics. First public release 1995; The R Foundation founded 2000. (The R Project · About · Wikipedia · R)

R extends through packages on CRAN. Text mining often uses tm, tidytext, quanteda, topicmodels, wordcloud2, ggplot2. VibeStat-Text bundles these in a built-in R engine for button-driven workflows on Windows.

R logo © The R Foundation. VibeStat-Text is an independent product, not an official R application.

R entry barriers — why it feels hard, and alternatives

Researchers new to R often face:

  • Environment setup — R, IDE (Posit), package dependencies
  • Scripting — syntax, data structures, error messages
  • Reproducibility — preprocessing, seeds, package versions
  • Korean preprocessing — morphological analyzers and dictionaries

VibeStatics built VibeStat-Text for people who want R-based text mining but were blocked by coding and setup — built-in R, buttons, dictionaries, and tutorials. Core computation still uses standard R packages. R · trust →

As an RStudio alternative focused on document corpora, it targets thesis work, policy reports, surveys, and interviews — not general-purpose data science alone.
